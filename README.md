# Chess — GitHub Pages test build

Тестовая веб-версия для GitHub Pages. Яндекс SDK не требуется.

## Онлайн
Клиент подключается к:
`wss://chess-game-server-yca1.onrender.com`

Онлайн-сервер поддерживает:
- быстрый поиск и комнаты;
- защиту от устаревшего поиска после отмены;
- переподключение к активному матчу в течение 60 секунд;
- сохранение ходов и часов на сервере;
- согласованную паузу 30/60/120 секунд;
- серверное завершение матча после истечения окна переподключения;
- чат в реальном времени с историей последних сообщений;
- вкладка «Ходы» с текущей нотацией;
- вкладка «Информация» со статусом соперника, контролем времени, ID матча и состоянием паузы.

## GitHub Pages
Загрузите содержимое этой папки в репозиторий и включите Pages → Deploy from branch → `main` → `/ (root)`.

## Render
Папка `server/` — отдельный Web Service для Render. После обновления серверного кода сделайте push в репозиторий, из которого Render выполняет deploy.
