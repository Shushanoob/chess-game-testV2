# Chess School — GitHub Pages test v2

Тестовая веб-версия для проверки онлайн-партий до публикации в Яндекс Играх.

Онлайн подключается к `wss://chess-game-servers.onrender.com`.

## Исправления и доработки
- Исправлен повторный «Быстрый поиск» после отмены: старый игрок удаляется из очереди, а устаревшие события старого матча игнорируются.
- Добавлена защита от повторного завершения одной партии и двойного начисления Elo.
- Онлайн-история помечается как онлайн-партия, а партии с ботом остаются отдельным режимом.
- Добавлена согласуемая пауза: 30 / 60 / 120 секунд. Соперник принимает или отклоняет запрос. Каждый игрок может использовать одну паузу за партию.
- Сервер ограничивает длительность паузы и проверяет matchId.
- Обновлён внешний вид: более тёмная шахматная оболочка, карточки, кнопки, тени и зелёные акценты в духе современных шахматных сервисов.

## GitHub Pages
Загрузите содержимое этой папки в корень репозитория → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Откройте полученную ссылку на двух разных устройствах. Яндекс SDK и Яндекс Лидерборд в этой тестовой сборке не подключаются.
