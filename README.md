# Шахматная школа — GitHub Pages test build V6

Тестовая клиентская сборка без зависимости от Яндекс SDK. Онлайн подключается к Render WebSocket:
`wss://chess-game-server-yca1.onrender.com`

## V6
- переработаны индикаторы легальных ходов: отдельные точки и кольца взятия;
- мобильный онлайн-матч получил отдельную панель функций;
- чат/ходы/информация открываются отдельным окном на телефонах;
- адаптация онлайн-матча для портретной и альбомной ориентации;
- добавлен режим «Я вообще не умею играть»;
- добавлены новые последовательные уроки для новичков;
- сохранены онлайн, пауза, переподключение, чат, история ходов и настройки фигур.

Для GitHub Pages: содержимое этого каталога публикуется как обычный статический сайт.
